# AAOCA / AAORCA 论文索引

整理日期：2026-07-31

本目录收录 **13 篇独立论文，共 106 页**，发表年份覆盖 2011-2026 年。其中包括 6 篇中国儿童/青少年队列研究，以及外科技术、功能影像和病例研究。

## 目录与命名规则

- `papers/`：有效论文，统一命名为 `年份_第一作者_中文短题_期刊.pdf`。
- 索引按正式出版年份倒序排列；同年按第一作者姓氏字母顺序排列。
- AAOCA：冠状动脉异常主动脉起源；AAORCA：右冠状动脉异常主动脉起源。
- WJPCHS：*World Journal for Pediatric and Congenital Heart Surgery*；JCTS：*Journal of Cardiothoracic Surgery*。
